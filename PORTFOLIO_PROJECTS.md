## 04. LAPD Crime Analysis

**Category:** Analysis and Public Safety

An analysis project built from the LAPD crime notebook and rendered HTML output. The project asks which victim age and sex groups appear most affected, where risk is concentrated, when crime peaks, and which crime types explain the pattern.

**Workflow:** Question -> Cleaning -> Organizing -> Modeling -> Visualization -> Insight

**Included artifacts:**

- `github-repos/la-crime-analysis/index.ipynb`
- `github-repos/la-crime-analysis/index.html`
- `github-repos/la-crime-analysis/notebook-markdown.md`
- `github-repos/la-crime-analysis/DATA.md`
- `github-repos/la-crime-analysis/README.md`

**Dataset note:**
