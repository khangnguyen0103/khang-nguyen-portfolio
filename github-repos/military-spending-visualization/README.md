# Military Spending Visualization

**Author:** Tran Tuan Khang Nguyen

This project visualizes military spending as a share of GDP across countries. The rendered HTML includes a choropleth map and a line graph for comparing global spending patterns.

## Workflow

1. **Modeling:** define the spending metric and comparison structure.
2. **Organizing:** prepare the country, year, and GDP-share fields.
3. **Mapping:** encode country-level spending into a choropleth view.
4. **Trend View:** compare change over time through line visualization.
5. **Visualization:** publish the rendered interactive HTML for readers.

## Included File

- `lab.html`: rendered visualization output.

## Portfolio Framing

This project belongs in the portfolio as a visualization project because it turns global policy data into an interactive map-and-trend experience that is easier to explore than a raw table.
